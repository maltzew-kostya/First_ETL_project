# My first ETL Project: Users & Orders
ETL-pipeline (не автоматизированный) для очистки и загрузки данных о пользователях и их заказов в БД PostgreSQL

## Pipeline описание

CSV - сгенерированная исходная "сырая таблица"

&darr;

Pandas - загрузка + преобразование данных 

&darr;

Python + psycopg - подключение к БД и перенос данных из csv в таблицы

&darr;

SQL - решение бизнес задач

## Структура проекта

*'\data\raw'* - исходные скаченные сырые данные;

*'\data\processed'* - очищенные и подготовленные csv файлы после преобразования;

*'\notebooks'* - анализ и визуализация в Jupyter;

*'\sql'* - SQL-скрипты: создание таблиц и бизнес логика;

*'\src'* - основной python код для загрузки данных в БД + запись логов
